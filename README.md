# Cidade Livre 3D

**Cidade Livre 3D** e um prototipo original de mundo aberto em terceira pessoa, inspirado no genero de acao urbana e conducao de jogos como GTA V. Nao utiliza personagens, mapas, marcas, modelos ou outros assets protegidos de GTA V.

## O que ja esta implementado
- Cidade 3D procedural com ruas, quadras e edificios com colisao.
- Personagem em terceira pessoa com camera controlada pelo mouse.
- Caminhada e corrida.
- Veiculo dirigivel, aceleracao, direcao e freio.
- Interacao para entrar e sair do carro.
- Objetivo de exploracao com recompensa de $500.
- HUD com dinheiro e nivel de procurado.

Este repositorio contem a primeira versao jogavel, com geometria criada por codigo e sem downloads de assets externos.

## Controles
| Tecla | Acao |
|---|---|
| W A S D | Mover / dirigir |
| Shift | Correr |
| E | Entrar ou sair do carro |
| Espaco | Frear |
| F | Aumentar nivel de procurado |
| Mouse | Controlar camera |
| Esc | Liberar o cursor |

## Executar no Godot
1. Instale Godot 4.3 ou superior.
2. Importe este repositorio como projeto existente.
3. Abra `project.godot` e pressione F6/F5.

## Executavel Windows
O workflow **Build Windows Portable** compila o projeto para Windows x86_64. Execute-o em **Actions → Build Windows Portable → Run workflow**. O pacote ZIP gerado contem o executavel portatil e os arquivos necessarios para rodar.
